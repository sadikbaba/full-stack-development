# Phase 1 Labs: Linux Fundamentals and SSH

This directory contains the practical work for **Phase 1: Linux Fundamentals and SSH**.

The goal is simple:

> Learn Linux by actually using it, not by memorizing commands.

Each lab is kept here so the work we do during the phase remains available for review and future practice.

## Labs

### Permissions

**Location:** `permissions/`

This lab is used to practice:

* Linux users and groups
* File ownership
* File and directory permissions
* Read, write, and execute permissions
* Numeric permissions such as `644` and `755`
* Changing permissions with `chmod`
* Understanding permission changes through real file operations

The lab contains:

```text
permissions/
├── private/
│   └── private.txt
├── public/
│   └── public.txt
└── README.md
```

The files are intentionally kept as part of the lab so we can continue modifying and testing them as we learn more.

## Documentation Rule

This lab grows with the lessons.

At the end of each study session, the practical work completed during that session will be documented here or in the relevant lab documentation.

Future topics will only be marked as completed after they have actually been practiced.
